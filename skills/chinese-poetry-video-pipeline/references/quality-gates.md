# 质量门与项目状态

## 总原则

只读取并执行当前任务适用的质量门，已有批准证据可复用，不因补记字段再次请求批准。每一阶段只在证据通过后晋级。文字计划不是视觉证明；工具返回成功不是像素证明；云端完成不是本地文件证明。

项目状态必须包含：当前阶段、已批准资产、待决问题、验证证据、成本授权、唯一下一步。不要把对话记忆当作唯一状态源。

## Gate 1：诗词与意境

通过条件：

- 题名、作者、朝代、原文和异文已核实；
- 朗诵取句与原文分开记录；
- 有一句明确视觉命题；
- 有支撑本诗的物象或关系，可变化、反复或停留；
- 末幕落点符合本诗，可转折、点题或保留余韵；
- 不是逐句“人物站在风景里”的列表。

## Gate 2：视觉方案

通过条件：

- 风格圣经写清媒介、色彩、光线、材质、人物、空间、禁止项；
- 风格能解释本诗，且与近期作品有足够差异；
- 镜头数量与情绪展开相称；4–7 幕只是短片常用范围；
- 镜头变化或有意重复有表达理由；必要时用矩阵排查无意重复；
- 空间关系适合所选媒介，不依赖厚雾掩盖结构；
- 明暗与冷暖有叙事归属。

## Gate 3：关键帧

逐张检查：

- 比例、分辨率和清晰度；
- 唯一视觉重心；
- 人物比例、视线、手脚、衣物连接、风向；
- 建筑、桥、栏杆、船、柱列等几何；
- 前中后景与遮挡；
- 暗部有结构、亮部不爆；
- 材质清楚而纹理克制；
- 无涂抹、重复碎纹、软焦、厚雾、多余人物、文字或水印；
- 共享角色/服装/道具锚点连续；
- 相邻幕变化或有意重复符合诗意，没有无意套用。

用序列预览复核节奏。单图好看但破坏序列关系，仍不通过。

## Gate 4：H3 提示词与批量任务

通过条件：

- 模式与参考图关系正确；
- 图片、图片组、提示词行、任务数严格匹配；
- 使用 `Picture` 和 `Shot`，不误写 `Video`；
- 每行含对齐句、`integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`；
- 本幕实际目标时长内有首帧余量、主动作、朗诵窗口和收束余量；8 秒只是默认；
- 动作可计数、可执行、有终点；
- 镜头运动只有一个主方向且幅度明确；
- 人物、物体数量、风向和连接关系被锁定；
- 负面约束针对本幕风险；
- 声音路线、取句与逐句时间预算已在提交前确定；当前模型、实际时长、分辨率与成本已确认；
- 用户已授权付费提交。

## Gate 5：生成片段

每段标记 `PASS`、`REVISE_PROMPT` 或 `REGENERATE`，不得用模糊的“差不多”。

检查：

- 首帧与参考一致；首尾帧模式能稳定落入尾帧；
- 人物身份、面部、肢体和服饰不漂移；
- 主动作完整，不原地踏步、不循环、不突然大幅舞动；
- 相机遵守提示，不乱变焦或环绕；
- 几何不融化，纹理不增殖；
- 画面无文字、UI、水印；
- 环境声和旁白（若有）可用；
- 有可剪的头尾余量。

结构性错误必须重生成。不要在剪辑阶段用遮挡、厚雾或过度裁切伪装。

## Gate 6：诗人人物化朗诵

本片使用旁白时，通过条件：

- 成片正文、异读、发音表和逐句时间目标已经核定；
- 声音人物卡明确分开可核实事实、创作推断与审美美化，不宣称历史声音复原；
- 年龄感、声区、音色重量、录音距离、发声支点、语速、停顿、情绪动作和禁止项都可执行；
- 新设计的独立配音已用短试听验证且获得批准；继续使用已批准原声或录音时复用原批准依据，不强制再生成；
- 最终音频保持同一人物身份；按气口选择连续录制后分段或支持身份锁定的生成方式，不把独立文本任务视为自动锁声线；
- 原始音频未被覆盖，失败试听不进入已确认区；
- 文件完整可解码，字幕内容与正文一致，时长、采样率、响度和 true peak 已检查；
- 易错字、同音字、异读、吞音和情绪重音经过人工听审，未把 ASR 当作唯一结论；
- 实际音频时长已回填镜头同步表，句末保留画面余韵；
- Skill、项目、命令、日志、元数据、manifest 和交付包中没有 API Key、请求头或临时下载 URL。

若本片有意不使用朗诵，记录“不适用”及替代声场设计后通过，不创建虚假的试听或审批记录。完整流程见 [poetry-voice.md](poetry-voice.md)。

## Gate 7：ChatCut 成片

通过条件：

- 时间线保持可编辑源片段；
- 镜头顺序和时长服从朗诵，不机械等分；
- 诗句大且清楚，单一主字体，描边在明暗背景都可读；
- 文字不遮挡主体与视线；
- 使用已确认的诗人／作品专属 AI 印章资产，不是时间线临时绘制的红框、系统字体或通用素材章；
- 印文逐字正确，章形、刀感和疏密有诗人气质与本诗意境依据，位置服从镜头留白且透明边缘干净；
- 没有细红线框或多余装饰；
- 旁白速度自然，停顿与画面动作对齐；
- 音乐不压旁白，句末有留白；
- 抽查开头、切镜前后、文字最密处和结尾的合成帧；
- 无黑帧、轨道错位、意外空隙或残留占位层。

## Gate 8：导出

通过条件：

- 云端 render 状态为完成；
- 下载文件完整且可解码；
- codec、分辨率、fps、时长符合项目；
- 音频流存在且内容正确（若成片需要声音）；
- 代表帧与 ChatCut 合成预览一致；
- 文件名、版本和本地路径已记录。

## Gate 9：发布包

通过条件：

- 封面以核准原文中的一句或两句经典诗句为第一视觉层，诗名缩小为第二视觉层；
- 缩略图先读到经典诗句，随后仍能辨认诗名，文字不遮挡人物关系或关键物象；
- 封面排版与书写风格能够从本诗意境和背景构图中得到解释，没有直接套用上一首模板；
- 标题、诗句、作者、印章无错字；印章不存在现代字体、通用红框、乱码或虚假历史复原表述；
- 印章设计说明、核准印文及来源、完整生成提示词、生成原图和透明定稿均已归档；
- 标题和笔记不夸大、不套用同一种钩子；
- 文字能说清诗的情绪矛盾和视觉转译；
- 成片、封面、可直接复制的纯文本发布文案均在 `01-发布成品`；
- 纯文本发布文案与核准正文语义一致：代码围栏内的一至两个提示词完整保留，交流问题、置顶评论和全部 `#话题标签` 未因 Markdown 转换丢失；并已完成一次真实复制发布模拟；
- 原文出处、创作说明、字幕与朗诵文本均有归档，不把创意解释冒充文学事实；
- 最终视频与封面完整解码、规格通过机器检查；最终 QA 明确记录成品批准及依据、人工听审结论，以及当前视频/封面/印章 SHA-256，格式见 release-package.md；路径、尺寸、时长、fps、编码和版本写入 `manifest.json`；
- `00-交付清单.md`、`manifest.json`、`SHA256SUMS.txt` 和 `04-质量验收/最终验收.md` 完整；
- 交付清单中没有 `PENDING`、`TODO`、未勾选必选项或不存在的文件；
- 包名与成片文件名使用一致的日期和版本标识；原位更新当前包时，manifest、验收记录和校验和必须同步重建；
- 默认只维护一个当前交付包；只有用户要求保留历史、需要审计快照或存在并行交付方案时才另建版本；
- `00-project-state.json` 更新为 `publish_ready`，并记录输出包相对路径、版本与 `COMPLETE` 状态。

输出包目录和必选/可选内容见 [release-package.md](release-package.md)。缺少任一必选项时只能标记 `INCOMPLETE`，不得宣称可发布。

## 跨系列差异化检查

维护最近作品表：

| 作品 | 主媒介 | 主色 | 主构图 | 人物尺度 | 主运动 | 声场 |
|---|---|---|---|---|---|---|

相同项较多时检查是否无意套用上一首；有明确诗意依据的共享元素可以保留，不以相同项数量退回方案。系列一致性由信息层级、印章的质量与使用层级、输出规格和审美纪律承担，不由复用同一枚通用章、重复画面或固定封面字体承担。成片字幕仍遵守单片单一主字体规则。
