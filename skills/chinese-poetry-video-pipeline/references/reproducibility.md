# 跨电脑复现

## 复现目标

复现的是明确的创作决策与质量要求，不是相同随机像素。记录本次要继承的空间、人物关系、媒介、材质、字幕身份和声音路线；只核对当前阶段已有的证据，不以主观分数宣称“90%相似”。

- **工作流复现**：安装同一版 Skill，按本诗重新选择视觉语言。
- **同一作品/系列复现**：使用批准参考帧及同一作品已批准资产，尽量保持生成模型、设置、字体与编辑条件。新诗仍设计自己的专属印章。
- 模型或工具变化时先做一张代表帧确认可接受的差异，不承诺像素复刻。

## 三张锚点

读取 `assets/style-anchors/manifest.json`，选择与当前命题相关的一到两张；需要不同媒介时可以不用。

- `01-celestial-scale.png`：尺度、不可达感、玉质与清晰建筑。
- `02-monochrome-youth.png`：留白、单色、朱砂点色与衣物动态。
- `03-human-gaze-distance.png`：真实视线、桥与河流关系、灯火明暗和冷暖。

锚点校准关系和质量，不要求重复景物。先把代表帧与所选锚点并排，检查明确借鉴的维度；符合本次批准方向后再扩组。不要用尚未发生的 H3、剪辑或交付结果给母帧补分。

## 环境

开始跨机制作前运行 `python3 scripts/check_environment.py`。

硬依赖是 Python 3.10+、FFmpeg/`ffprobe` 和可调用 Skill 的环境。图像生成、H3 访问、ChatCut、字体与声音工具按阶段确认。环境报告能检查文件与工具安装，不能证明账号权限、编辑器连接或实际生成可用。

缺少工具时停在相应的可交付阶段，给出手工交接材料，不擅自换工具或提交付费任务。发布规格与当前模型设置按当次需要核实。

## 复现顺序

1. 记录 Skill 版本、模型可见名称、日期与环境。
2. 读本诗文本、批准资产与声音路线，确认本次继承的创作决策。
3. 对照代表帧；方向通过后扩组，整组核对人物、服饰、空间与节奏。
4. 用项目实际时长生成和剪辑，不固定八秒，也不为模仿上一首改变本诗表达。
5. 按质量门检查真实成片，将版本、输入、批准依据和校验和写入交付记录。
